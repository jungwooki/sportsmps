# mps-sportsmps

스포츠MPS 부모님 안내 페이지

`mps-sportsmps` 프로젝트는 부모님이 모바일에서 읽는 스포츠MPS 소개 사이트입니다. 별도 빌드나 패키지 설치 없이 `index.html`을 열면 됩니다.

## 파일 구조

```text
index.html                 메인 페이지 (11개 섹션)
assets/
  css/
    main.css               기본 레이아웃·A2Z 폰트
    reports.css            실제 리포트 미리보기
    mps-sportsmps.css            유럽 사례·사진·가격·플로팅 메뉴
  js/
    navigation.js          목차·페이지 이동·진행 표시
    reports.js             리포트 모달·탭·스와이프
    dialogs.js             상담예약·가격 모달
  fonts/                   A2Z 400·500·700·800
  images/
    logo-black.png
    soccer-boy.png
    physical-01.jpg
    field/                 센터·현장 사진 3장
    reports/               익명화된 리포트 미리보기 9장

.nojekyll
README.md
```

## GitHub 업로드

이 폴더 **안의 내용 전체**를 사이트 저장소 루트에 올립니다. `index.html`과 `assets/`의 상대 위치를 유지해 주세요. 별도의 환경변수·API 키·외부 JavaScript 라이브러리는 없습니다. GitHub Pages를 사용할 경우 이 정적 사이트가 있는 브랜치와 폴더를 배포 대상으로 선택합니다.

현재 단계에서는 로컬 파일만 정리했으며, 저장소 생성·커밋·푸시는 수행하지 않았습니다.

## 자료 기준

- 디자인: 제공된 guide의 화이트·오렌지 색상과 A2Z 글꼴.
- 유럽 사례 및 실제 사진: 제공된 사업제안서 HTML. 본문에 Premier League와 FIFA Training Centre의 원문 링크를 포함합니다. 센터 사진은 신도림, 현장 사진은 2026 청춘양구 축구페스티벌입니다.
- 가격·포함 항목: 제공된 MPS 프로그램 안내 PDF. 일반과 협약팀 가격, 기본 프로그램과 추가 옵션을 구분했습니다. 의료기관 진료비는 별도입니다.
- 모바일 리포트: 제안서에 포함된 실제 화면의 개인정보 영역을 샘플 정보로 대체한 이미지입니다. 화면 속 버튼은 이미지의 일부이며 실제 앱 기능은 아닙니다.
- 상세 결과지: 제공된 PDF의 일부 페이지를 익명화한 뒤 420px 너비의 PNG 썸네일로 저장했습니다. 이름·학교·선수번호·날짜 등의 제거는 CSS 가림이 아닌 픽셀에 반영되어 있습니다. 원본 PDF·개인정보 텍스트·익명화 전 이미지는 포함하지 않습니다.
- 일반MPS: 공부하는 10–15세, 초등학교 4학년~중학교 3학년 대상. 멘탈(학습·일상), 피지컬(체질건강), 성장단계(키 성장)를 함께 살핍니다. 스포츠MPS와 구분하며, 기존 가격표와 실제 리포트 샘플은 스포츠MPS 기준으로 표시합니다.

## 정리 및 확인

- `mpsindex.html`을 `index.html`로 변경했습니다.
- 이전 HTML과 미사용 원본 사진은 업로드 폴더 밖의 guide 참고자료 폴더로 옮겨 보관했습니다.
- 실제 사용하는 파일만 남기고 CSS·JS·폰트·이미지를 종류별로 정리했습니다.
- 모든 로컬 HTML·CSS 참조와 사용 자산을 검사했고, 320·390·430·1440px Chrome 화면에서 이미지 로드·레이아웃·목차·리포트/가격/상담 모달을 확인했습니다.

## Pretendard 모바일 버전

- `index.a2z.html`: 기존 A2Z 디자인.
- `index.html`: 같은 내용·기능에 Pretendard를 적용한 현재 메인 페이지.
- `assets/css/pretendard.css`: 대안 버전에서만 불러오는 글꼴·크기·행간·여백 설정. 큰 제목을 줄이고 본문과 터치 영역은 읽고 누르기 편한 크기로 유지합니다.
- `assets/fonts/PretendardVariable.woff2`: 로컬 가변 폰트. 배포 라이선스는 `Pretendard-OFL.txt`에 포함했습니다.
- `index.a2z.html`은 이전 A2Z 버전 보관용입니다. 현재 안내 내용과 테마 변경은 `index.html`에 적용합니다.

## 스포츠MPS 핵심 모델

성장판 검사·뼈나이·성장속도 → 성장단계 확인 → 피지컬·부상위험 관련 지표 및 멘탈성향 해석 → 선수별 훈련 방향 → 3개월 주기 재평가의 흐름을 명시했습니다. 유연성·민첩성·근력·지구력·밸런스는 선수별 결과에 따라 설명하는 훈련 영역이며, 성장단계만으로 일괄 훈련 처방을 제시하지 않습니다.

‘900명 이상 성장기 엘리트 선수 표준 데이터’는 운영자가 이번 수정 요청에서 제공한 MPS 보유 현황입니다. 국가 표준이나 독립적인 타당도 검증 수치로 표현하지 않았습니다. 프로 진입은 장기 로드맵의 목표이며 결과 보장으로 표현하지 않습니다.

### 쇼츠와 페이지 전환

- 바이오밴딩 설명 아래에 유튜브 쇼츠 `2czTwDPOxnk`를 배치했습니다. 로컬 썸네일을 누르면 세로형 YouTube 플레이어가 생성되며, 누르기 전에는 영상이 로드되지 않습니다.
