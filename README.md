# MPS SportsMPS 2 · 간결한 부모님 안내

10–15세 선수 부모님을 위한 7페이지 모바일 안내입니다.

1. MPS 바이오밴딩: 성장단계에 따라 멘탈·피지컬 결과 해석
2. 필요성: 성장단계를 기준으로 멘탈·피지컬 결과를 해석하는 바이오밴딩 도표
3. 검사: 성장·멘탈·피지컬 측정과 진행 흐름
4. 활용: 결과 → 훈련 목표 → 변화 확인
5. 모바일 리포트와 상담 리포트 샘플
6. 만든 사람들
7. 가격·예약

사용자에게 표시하는 용어는 ‘성장단계’로 통일했습니다. 실제 리포트 이미지의 원문은 보존했습니다. 그래프는 가상 관찰 기록 예시입니다.
기존 mps-sportsmps와 분리된 폴더이며 자체 미디어와 글꼴을 포함합니다. index.html을 정적 서버에서 제공하면 됩니다.

최종 구성: 해외 사례와 영역별 개별 소개 페이지는 제외했습니다. 결과 활용은 성장플랜·12주 그래프로 보여주고, 마지막 페이지는 가격·예약과 접을 수 있는 제휴센터·법적 고지를 묶었습니다. 기존 영상 팝업을 유지합니다.

빠른 안내 버튼(샘플리포트 보기·상담예약·가격)은 우하단의 반투명 플로팅 메뉴로 제공하며, 하단에는 페이지 넘기기만 둡니다.
